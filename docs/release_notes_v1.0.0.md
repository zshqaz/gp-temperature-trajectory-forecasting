# v1.0.0 -- MSc dissertation reproducibility release

This release freezes the source code, experiment configurations, tests, compact numerical results, optimisation diagnostics, and validation records accompanying the dissertation.

The ERA5-Land source CSV is not redistributed. Retrieval instructions and the SHA-256 identifier of the analysed file are included under `docs/data_acquisition.md`.

The release does not create or claim a Zenodo DOI.
